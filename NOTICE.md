# Credits and publishing boundary

This is an independent derivative of [shiyang1026/magpie-claude-science](https://github.com/shiyang1026/magpie-claude-science), developed by Sia, under the original MIT license (see LICENSE). Original authorship is retained.

The repository only ships the local Magpie-to-Science bridge and installer. It does not include Claude Science application binaries, OAuth credentials, user conversations, checkpoints, or the upstream author’s npm publishing credentials.

The `lite` fork is offered for source installation and GitHub package downloads; it is not published to upstream npm and the release workflow is intentionally omitted.
